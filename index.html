PROJETOS

MODSY

Projeto de Conclusão de Curso desenvolvido no SENAI. O Modsy é um guarda-roupa inteligente que utiliza IoT e Inteligência Artificial para auxiliar pessoas com deficiência visual na identificação e organização de roupas,promovendo mais autonomia e acessibilidade. Durante o projeto, participei do levantamento de requisitos, prototipação, desenvolvimento e apresentação da solução, aplicando conhecimentos em programação, banco de dados, integração de tecnologias e trabalho em equipe.

BLOG PESSOAL

Aplicação Full Stack com CRUD completo de publicações, usuários e temas. O back-end foi desenvolvido em Java com Spring Boot e Spring Security, com API documentada no Swagger e testada no Insomnia. O front-end foi criado em React com Axios, enquanto a API e o banco de dados estão hospedados no Render. O deploy da interface será realizado em breve no Vercel.
