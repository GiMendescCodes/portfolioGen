O **Projeto Portfólio Pessoal** é um site desenvolvido com **HTML, CSS e JavaScript**, criado para apresentar informações profissionais, projetos, habilidades e formas de contato de maneira moderna, organizada e totalmente responsiva.

O projeto foi desenvolvido com foco em boas práticas de desenvolvimento Front-end, oferecendo uma navegação intuitiva, animações suaves e adaptação para diferentes tamanhos de tela.

---

## Funcionalidades

- Estrutura desenvolvida com **HTML5 semântico**
- Layout **100% responsivo** para desktop, tablet e mobile
- Estilização moderna utilizando **CSS3**
- Animações e efeitos visuais
- Menu de navegação
- Seção de projetos
- Currículo disponível para download
- Formulário de contato
- Página de confirmação de envio (`success.html`)
- Interface simples, organizada e intuitiva

## Executando Localmente

### Pré-requisitos

- Visual Studio Code
- Extensão **Live Server**

### Passos

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Acesse a pasta do projeto:

```bash
cd seu-repositorio
```

3. Abra o projeto no VS Code:

```bash
code .
```

4. Clique com o botão direito em `index.html` e selecione **Open with Live Server**.
